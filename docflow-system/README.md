# Система документооборота организации с чатом

Веб-приложение для управления документами организации с встроенным чатом для общения сотрудников.

## Возможности

- 📄 **Управление документами**
  - Создание новых документов с указанием заголовка, автора, типа и содержания
  - Просмотр списка всех документов
  - Редактирование документов (изменение заголовка и статуса)
  - Удаление документов
  - Типы документов: общий, договор, отчет, служебная записка, приказ
  - Статусы: активен/архив

- 💬 **Чат для общения**
  - Обмен сообщениями в реальном времени
  - Отображение списка онлайн-пользователей
  - Индикатор набора текста
  - История сообщений

- 🔄 **Real-time обновления**
  - Мгновенное обновление списка документов при изменениях
  - Сообщения в чате доставляются в реальном времени
  - Уведомления о подключении/отключении пользователей

## Технологии

- **Backend**: Node.js, Express, Socket.IO
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Хранение данных**: В памяти (для демонстрации)

## Установка и запуск

1. Установите зависимости:
```bash
npm install
```

2. Запустите сервер:
```bash
npm start
```

3. Откройте браузер и перейдите по адресу:
```
http://localhost:3000
```

## API Endpoints

### Документы
- `GET /api/documents` - Получить список всех документов
- `POST /api/documents` - Создать новый документ
- `GET /api/documents/:id` - Получить документ по ID
- `PUT /api/documents/:id` - Обновить документ
- `DELETE /api/documents/:id` - Удалить документ

### Сообщения
- `GET /api/messages` - Получить последние 50 сообщений

## Socket.IO события

### Клиент → Сервер
- `join` - Подключение пользователя
- `chat-message` - Отправка сообщения
- `typing` - Индикатор набора текста

### Сервер → Клиент
- `document-created` - Создан новый документ
- `document-updated` - Документ обновлен
- `document-deleted` - Документ удален
- `chat-message` - Новое сообщение в чате
- `current-users` - Список текущих пользователей
- `user-joined` - Пользователь подключился
- `user-left` - Пользователь отключился
- `user-typing` - Пользователь печатает

## Примечание

Данная система хранит данные в оперативной памяти сервера. Для производственного использования рекомендуется добавить базу данных (MongoDB, PostgreSQL и т.д.) для постоянного хранения документов и сообщений.
