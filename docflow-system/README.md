# Система документооборота - Расширенная версия

Профессиональная система документооборота для организации с чатом, аутентификацией и загрузкой файлов.

## 🚀 Новые возможности

- 🔐 **Аутентификация и регистрация** - JWT токены, хеширование паролей bcrypt
- 📎 **Загрузка файлов** - Прикрепление файлов к документам
- ✅ **Валидация данных** - Express Validator
- 👤 **Управление пользователями** - Регистрация, вход, выход
- 🔒 **Защищенные API** - Middleware авторизации

## Основные возможности

- 📄 Создание, просмотр, редактирование и удаление документов
- 💬 Чат с сообщениями в реальном времени
- 👥 Список онлайн-пользователей
- 🔄 Мгновенные обновления через Socket.IO
- 📊 Типы документов: договоры, отчеты, служебные записки, приказы

## Технологии

- **Backend:** Node.js, Express
- **Real-time:** Socket.IO
- **Auth:** JWT, bcryptjs
- **Upload:** Multer
- **Validation:** Express Validator
- **Frontend:** HTML5/CSS3/JavaScript

## Установка

```bash
npm install
```

## Запуск

```bash
npm start
```

Откройте http://localhost:3000 в браузере.

## API Endpoints

### Аутентификация
- `POST /api/auth/register` - Регистрация нового пользователя
- `POST /api/auth/login` - Вход в систему

### Документы
- `GET /api/documents` - Получить все документы
- `POST /api/documents` - Создать документ (требуется авторизация)
- `GET /api/documents/:id` - Получить документ по ID
- `PUT /api/documents/:id` - Обновить документ (требуется авторизация)
- `DELETE /api/documents/:id` - Удалить документ (требуется авторизация)

### Файлы
- `GET /api/files/:filename` - Скачать файл

### Чат
- `GET /api/messages` - Получить последние 50 сообщений
